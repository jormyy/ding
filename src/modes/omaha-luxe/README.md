# Omaha Luxe

Omaha Luxe is a four-hole-card Ding variant with deeper private-card texture and larger street-to-street swings.

## Rules

- Mode id: `omaha-luxe`
- Deal: 4 private hole cards per hand.
- Board: 5 shared community cards.
- Visibility: hole cards are private until reveal; community cards reveal 0 / 3 / 4 / 5 across preflop / flop / turn / river.
- Scoring: standard high poker hand using the four hole cards plus the shared board.
- Team score: pairwise inversions between the table's final ranking and the true high-hand ranking.
