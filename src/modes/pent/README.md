# Pent

Pent is a five-hole-card Ding variant where each hand carries enough private texture to make board changes especially volatile.

## Rules

- Mode id: `pent`
- Deal: 5 private hole cards per hand.
- Board: 5 shared community cards.
- Visibility: hole cards are private until reveal; community cards reveal 0 / 3 / 4 / 5 across preflop / flop / turn / river.
- Scoring: standard high poker hand using the five hole cards plus the shared board.
- Team score: pairwise inversions between the table's final ranking and the true high-hand ranking.
