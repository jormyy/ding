# Triad

Triad is a three-hole-card Ding variant with more private texture and stronger late-street swings than Classic Ding.

## Rules

- Mode id: `triad`
- Deal: 3 private hole cards per hand.
- Board: 5 shared community cards.
- Visibility: hole cards are private until reveal; community cards reveal 0 / 3 / 4 / 5 across preflop / flop / turn / river.
- Scoring: standard high poker hand using the three hole cards plus the shared board.
- Team score: pairwise inversions between the table's final ranking and the true high-hand ranking.
